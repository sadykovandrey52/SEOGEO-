# ООО «Вольфагролес» — WordPress-сайт

Рабочая сборка многостраничного B2B-сайта: лёгкая Gutenberg-совместимая тема `wolfagroles` и функциональный плагин `wolfagroles-core`.

## Визуальный прототип

[Открыть опубликованный многостраничный макет](https://wolfagroles-site.sadykov-andrey52.chatgpt.site). Текущая версия включает 83 самостоятельные посадочные страницы: 18 услуг, 30 типов изделий, 4 материала, 13 B2B-сегментов, оборудование, типовые производственные кейсы и экспертные статьи.

Визуальная система собрана на оригинальных изображениях, сгенерированных специально для проекта: производство, лазерная резка, гибка, сварка, каталог точных деталей и корпусные изделия. Присланные фотографии и видео в интерфейсе не используются. Раздел «С кем работаем» содержит отдельную страницу для каждого сегмента и три честных кейса-сценария без вымышленных клиентов, цен, сроков или технических параметров.

Сборка намеренно не публикует неподтверждённые числовые параметры, цены и сроки. Возможность изготовления и производственный маршрут подтверждаются после проверки документации.

## Состав

- `wp-content/themes/wolfagroles/` — тема, шаблоны, стили и интерфейс.
- `wp-content/plugins/wolfagroles-core/` — CPT, метаполя, настройки, SEO/schema, форма расчёта, загрузка файлов и начальный контент.
- `docs/` — карта URL, реестр фактов, редакторская и эксплуатационная документация, QA и перечень недостающих данных.
- `tools/build.sh` — проверка структуры, упаковка и контрольные суммы.
- `dist/` — установочные ZIP после запуска сборки.

## Требования

- актуальная стабильная WordPress;
- поддерживаемая хостингом версия PHP;
- HTTPS;
- постоянные ссылки вида «Название записи»;
- настроенная серверная почта/SMTP;
- запрет прямого веб-доступа к `wp-content/uploads/wolfagroles-leads/` на уровне Nginx/Apache.

## Быстрая установка

1. Создайте резервную копию и разверните чистый staging WordPress.
2. В админке откройте «Внешний вид → Темы → Добавить» и загрузите `dist/wolfagroles-theme.zip`.
3. Откройте «Плагины → Добавить» и загрузите `dist/wolfagroles-core.zip`.
4. Активируйте тему, затем плагин. Плагин создаст обязательные страницы и черновики направлений.
5. Откройте «Настройки → Постоянные ссылки» и сохраните структуру «Название записи».
6. Заполните «Настройки → Вольфагролес»: получатель заявок, режим работы, координаты, лимиты файлов и ссылки на карту.
7. Настройте SMTP вне репозитория и отправьте тестовую заявку с разрешённым и запрещённым файлами.
8. Подтвердите коммерческие факты, заполните источники и даты проверки; только затем публикуйте соответствующие страницы.
9. Юридически утвердите политику и согласие до production.
10. После проверки снимите `noindex` со staging только на production и отправьте `/wp-sitemap.xml` в панели вебмастеров.

WP-CLI-вариант:

```bash
wp theme install dist/wolfagroles-theme.zip --activate
wp plugin install dist/wolfagroles-core.zip --activate
wp rewrite structure '/%postname%/' --hard
wp rewrite flush --hard
```

## Сборка

```bash
bash tools/build.sh
```

Результат: два установочных ZIP и `dist/SHA256SUMS.txt`. CI повторяет PHP lint, проверку обязательных файлов и сборку артефактов.

## SMTP, кеш и аналитика

- SMTP: используйте один механизм хостинга или один SMTP-плагин; пароли не помещайте в Git.
- Кеш: включайте один механизм, соответствующий серверу. После обновления шаблонов очищайте page cache.
- SEO: `wolfagroles-core` уже создаёт canonical, description, Open Graph и JSON-LD. Не включайте параллельную генерацию этих тегов другим SEO-плагином.
- Аналитика: тема отправляет события в `dataLayer`. Счётчики подключаются после настройки фактического согласия на cookies; ID не зашиты в код.

## Staging → production и откат

Перед переносом сделайте экспорт БД и копию `wp-content`. Переносите тему, плагин, медиа и БД штатным инструментом хостинга; затем замените URL, очистите кеш и повторите smoke-test из `docs/qa-report.md`.

Откат: восстановите БД и `wp-content` из одной согласованной точки, очистите object/page cache и снова сохраните постоянные ссылки. Не откатывайте только БД или только файлы: версии схемы и кода должны совпадать.
