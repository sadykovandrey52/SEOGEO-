# Плагины и инфраструктурные механизмы

| Компонент | Назначение | Лицензия/стоимость | Решение |
|---|---|---|---|
| wolfagroles-core | CPT, факты, настройки, форма, SEO metadata, schema, robots, события | Собственный код | Обязательно; один функциональный и SEO-механизм |
| SMTP | Доставка писем | По выбору хостинга | Один механизм; секреты вне Git |
| Page cache | Кеш страниц | По стеку хостинга | Один механизм; не дублировать |
| Backup/security | Копии, восстановление, 2FA/ограничение входа | По инфраструктуре | Выбрать после подтверждения хостинга |

Не включать параллельную генерацию canonical, Open Graph или schema сторонним SEO-плагином. Если заказчик решит перейти на другой SEO-плагин, сначала отключить SEO-модули `wolfagroles-core` в коде и проверить отсутствие дублей.
