# Инструкция редактора

## Глобальные данные

«Настройки → Вольфагролес» — единый источник телефона, e-mail, адреса, получателя заявок, лимитов файлов, координат и ссылок. Не дублируйте контакты вручную в шаблонах.

## Коммерческие сущности

В админке доступны: услуги, изделия, материалы, отрасли, оборудование и проекты.

Перед публикацией:

1. Сформулируйте один интент и один H1.
2. Заполните прямой ответ на 40–80 слов.
3. Выберите «ПОДТВЕРЖДЕНО».
4. Укажите источник и дату проверки.
5. Заполните видимый контент без обещаний, которых нет в источнике.
6. Добавьте характеристики JSON только с заполненными значениями.
7. Добавьте 6–10 фактических вопросов и ответов JSON.
8. Укажите ID связанных записей.
9. Заполните SEO Title и Description.
10. Проверьте preview, затем публикуйте. Если статус не подтверждён, плагин вернёт запись в черновик.

Пример характеристик:

```json
[
  {"parameter":"Материал","value":"Подтверждённая марка","unit":""},
  {"parameter":"Толщина","value":"Подтверждённое значение","unit":"мм"}
]
```

Пример FAQ:

```json
[
  {"question":"Что нужно для расчёта?","answer":"Фактический ответ без рекламных обещаний."}
]
```

## Статьи

Укажите автора, дату обновления и ссылки на источники. Не создавайте одинаковые SEO-абзацы и страницы под простую замену города.

## Изображения

Загружайте оригинальные фотографии в WebP/AVIF/JPEG с корректными размерами. Alt описывает то, что видно и важно для страницы. Для декоративного изображения оставляйте alt пустым.
